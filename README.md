# ArtiosCAD Fast Export

Приложение для незаметного экспорта из локального ArtiosCAD 22.07 через группы выводов. Целевая платформа: Windows 10, пользователи без прав администратора.

## Группы вывода

- `Plotter (ACM / DXF)`
- `Plotter (ACM / DXF / PDF)`
- `Plotter (ACM / DXF / PDF / EPS)`

Результаты сохраняются рядом с исходным `.ARD`, повторный вывод заменяет предыдущие файлы выбранной группы. Пользователь работает только в ArtiosCAD после первоначальной настройки.

Приложение запускается исключительно с сетевого диска. Локальное копирование EXE не предусмотрено. Администратор собирает и публикует версии централизованно.

## Статус

Реализован пилот 0.1 для проверки на ArtiosCAD: обработчик заданий, конвертер ACM → DXF на основе исходного прототипа, сетевые загрузчики, настройщик трёх групп, сборка и публикация. Рабочие данные пользователей в репозиторий не включены.

Пилот использует `%LOCALAPPDATA%\ArtiosCADFE`. Внутри группы Begin убирает прежние входы в карантин, штатные Outputs записывают новый комплект, Finish делает снимки файлов и публикует результаты. Незавершённая/повторная подготовка блокирует дальнейший вывод до сброса при закрытом ArtiosCAD. Поддерживается один экземпляр ArtiosCAD и последовательный вывод.

Реальных ARD/ACM, эталонных DXF/PDF/EPS и XML запуска пока нет. Интеграцию и точность геометрии потребуется проверить на ArtiosCAD 22.07 до производственного использования.

**Начало проверки:** [инструкция пилота](docs/PILOT_RU.md). Запустите `Build.cmd`, распакуйте полученный ZIP на сетевой диск, затем запустите от пользователя сетевой `Setup.exe` при закрытом ArtiosCAD. Он сохранит backup выбранного clientdflt.zip перед изменением Outputs. Сначала проверяйте группу ACM/DXF на копии ARD. EPSF пока экспериментален.

## Структура

- `docs/architecture.md` — архитектура и ограничения.
- `docs/PILOT_RU.md` — установка, проверка и откат пилота.
- `src/Core` — геометрия, задания, публикация с восстановлением, настройка Outputs.
- `src/Runtime` — команды приложения и сообщения об ошибках.
- `src/Launcher` — запуск выбранного сетевого релиза.
- `scripts/Build.ps1`, `scripts/Publish.ps1` — сборка с тестами и публикация.
- `tests` — изолированные синтетические проверки; ArtiosCAD не требуется.
- `config/publish.example.json` — параметры сборки и публикации.
- `config/runtime.example.json` — пример параметров обработки заданий.

Сборка использует `*.example.json` по умолчанию. Реальные сетевые пути храните в игнорируемых `*.local.json` и передавайте параметрами `-Config` / `-RuntimeConfig`. Для публикации нужен реальный UNC-путь; каталог `artifacts` в Git не включается. Требуется .NET Framework 4.5+ и Windows PowerShell 5.1, NuGet и отдельный SDK не используются.

Комментарии к ключевой логике написаны на русском. Алгоритм геометрии и XML-структура Outputs перенесены из предоставленного исходного пакета v2.3 с проверками ошибок и новой файловой архитектурой. Полноценная проверка PDF/EPS и промышленная поддержка параллельного вывода пока не заявляются.
